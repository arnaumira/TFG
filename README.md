# TFG
La formació pràctica del grau d’Infermeria implica la coordinació de diversos perfils i la gestió d’un gran volum
d’informació que, sovint, es tramita en paper, fet que provoca pèrdues de documentació i dificulta el seguiment de l’alumnat.
Aquest treball té com a objectiu dissenyar i desenvolupar una plataforma web multidispositiu que centralitzi la gestió, la
comunicació i el seguiment acadèmic de les pràctiques d’infermeria a l’Hospital Universitari Parc Taulí. Com a resultat, s'ha
obtingut una aplicació funcional basada en web que integra l'autenticació per rols, un calendari interactiu de sessions, el registre d'assistència mitjançant codis QR i un sistema d'avaluació per rúbriques digitals. La solució unifica en una sola eina processos que abans estaven fragmentats, millora la traçabilitat de tot el procés i ofereix una experiència adaptada a cada perfil. Com a treball futur, seria interessant fer el desenvolupament de vàries funcionalitats per a donar-li més riquesa al projecte, com per exemple, una ampliació dels mètodes de registre d’assistència o desenvolupar un mòdul de comunicació interna, i, finalment, fer el desplegament en producció.
